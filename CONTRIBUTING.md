# Contributing to Adaptive Resource Monitor

[Contribution guide on the ARM Wiki](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/wiki/How-to-Contribute) · [Development roadmap](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/wiki/Development-Roadmap)

Search [open and closed issues](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/issues) before opening a report. Use the [issue chooser](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/issues/new/choose) to pick the appropriate form. Include the ARM version, distribution, expected and actual behavior, and a minimal reproduction. Follow the [diagnostic privacy guidance](SUPPORT.md#share-diagnostics-safely).

Open a pull request from your fork on [GitHub](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/pulls) or coordinate a contribution in [Gitea](https://phantom.zapto.org/gitea/sonja/Adaptive_Resource_Monitor). Discuss the intended scope in an issue first. Base the changes on the current default branch. Describe the problem, the change and the validation performed, and reference the issue as `Refs #123`. Submit the patch directly to the original project through the [Design Creations contact form](https://www.designcreations.us/contact/index.php) or coordinate a submission with a maintainer. Please only contribute material that you have the right to submit on the terms in [LICENSE.md](LICENSE.md). Reviewers use the [issue lifecycle](ISSUE_MANAGEMENT.md).

## Derivative distribution permission

Private non-commercial development and contributions directly to the project are covered by the license. Before distributing a derivative publicly, obtain affirmative written permission from the Licensor. Commercial use also requires separate written permission as described in the license.

Use [Register Derivative](https://www.designcreations.us/software/register-derivative.php?product=adaptive-resource-monitor) for the formal permission request and confidential details. You can describe a planned project and proposed repository, distribution and support locations. Use the [derivative inquiry form](https://github.com/sonjamichelle/Adaptive_Resource_Monitor/issues/new?template=09-derivative-request.yml) for optional public, non-confidential questions. The registration reference confirms receipt of your request. Obtain affirmative written permission from the Licensor before distributing a derivative publicly.

Independently distributed derivatives are supported by their respective maintainers. The authoritative terms are in [LICENSE.md](LICENSE.md).
